# BarvalAILocalSite

Сайт ИИ Локальный - персональный локальный ассистент на основе искусственного интеллекта    

Он осуществляет:  
- чат с локальной ИИ-моделью (Ollama, используются модели - qwen3:4b-instruct-2507-q4_K_M, qwen3-vl:8b-instruct-q4_K_M, qwen3:8b-q4_K_M)  
- создание изображений по описанию (Automatic1111, модель - cyberrealisticXL_v90.safetensors)  
- анализ изображений и файлов .png, .jpg, .jpeg  
- анализ текста из файлов .txt, .pdf [в разработке]  
- анализ голосовых сообщений [в разработке]  
- воспроизведение голосовых сообщений [в разработке]  
- домашнее видеонаблюдение  

## Требования
- виртуальная машина или физический сервер с установленными Docker и Docker-compose  
- доступ в Интернет (для скачивания моделей), либо локально размещённые Docker-образы и файлы моделей  
- доступ к сервису Ollama (модели - qwen3:4b-instruct-2507-q4_K_M, qwen3-vl:8b-instruct-q4_K_M, qwen3:8b-q4_K_M)  
- доступ к сервису Automatic1111 (модель - cyberrealisticXL_v90.safetensors)  
- доступ к сервису OpenAI Whisper  
- доступ к сервису room-snapshots-api (опционально для домашнего видеонаблюдения)  

### ВАЖНО: Обязательные файлы конфигурации
Для работы приложения **ОБЯЗАТЕЛЬНО** наличие следующих файлов со всеми необходимыми переменными:  

1. **.env** - системные параметры (все переменные обязательны, см. .env.example)  
2. **users.list** - список данных пользователей (минимум один пользователь, см. users.list.example)  

## Запуск
1. Убедитесь, что Ollama запущена и доступна (вариант проверки если сервер Ollama на том же сервере):
```bash
curl http://localhost:11434/api/tags
```
2. Скачайте в Ollama необходимые модели:  
```bash
ollama pull qwen3:4b-instruct-2507-q4_K_M
ollama pull qwen3-vl:8b-instruct-q4_K_M
ollama pull qwen3:8b-q4_K_M
```
3. Убедитесь, что Automatic1111 запущен и доступен (вариант проверки если сервер Automatic1111 на том же сервере):
```bash
curl http://localhost:7860
```
4. Скачайте необходимые модели с сайта https://civitai.com/models (для скачивания моделей может потребоваться регистрация на сайте https://civitai.com/):  
```text
Рекомендуются модели серий CyberRealistic, например:
cyberrealisticXL_v90.safetensors  
```
5. Скопируйте .env.example в .env и отредактируйте при необходимости (обязательно создайте свой SECRET_KEY):
```bash
cp .env.example .env
```
6. Скопируйте users.list.example в users.list и заполните учётными данными (обязательно создайте хотя бы одну запись):
```bash
cp users.list.exapmle users.list
```
7. Запустите приложение:
```bash
docker-compose up --build    
```
8. Откройте http://localhost:5000 и войдите с учетными данными из users.list
