# BarvalAIMultiChatSite

ИИ МультиЧат сайт - сайт для работы с большими языковыми моделями (LLM)    

Предоставляет доступ к нескольким мощным LLC-моделям через API OpenRouter,  
позволяет работать с:  
- текстовыми данными  
- вводить изображения (некоторые модели)  
- использовать "глубокое мышление" (некоторые модели)  

## Требования
- доступ в Интернет  
- доступ к сервисам API от https://openrouter.ai  
- заполненный файл - users.list  
- для запуска в docker-compose - docker, docker-compose  
- для запуска локально - python3, установленные через pip зависимости из файла requirements.txt  

## Использование
Необходимо файл:
- **users.list** - список данных пользователей (e-mail, пароль, API-ключ).  
API-ключ пользователям необходимо предварительно получить на https://openrouter.ai
