# Интеграция камер

Модуль камер подключается к отдельному сервису `room-snapshot-api`. Подробные инструкции по развёртыванию см. в [../services/README.md](../services/README.md) и [services/room-snapshot-api/README.md](../services/room-snapshot-api/README.md).

## Управление камерами (панель администратора)

В панели администратора есть вкладка **«Камеры»** с полным набором CRUD-операций:
- **Синхронизация** – импорт списка камер из room-snapshot-api (эндпоинт `/rooms`)
- **Включить/Отключить** – по отдельности для каждой камеры
- **Предпросмотр миниатюр** – снимки с камер загружаются лениво с кэшированием в localStorage
- **Распознавание русских названий** – морфологический анализ через pymorphy3 формирует все грамматические склонения (именительный, винительный, предложный падежи) для каждого названия помещения. Благодаря этому ИИ правильно понимает фразы: «покажи гостиную», «что в гостиной», «на кухне» и т.п.

Данные о комнатах с камерами хранятся в таблице базы данных `camera_rooms` (поля: code, name_forms, enabled, sort_order).

## Конфигурация
```bash
CAMERA_API_URL=http://flai-room-snapshot-api:5000
CAMERA_ENABLED=true
CAMERA_API_TIMEOUT=15
CAMERA_CHECK_INTERVAL=30
```

## Права доступа к камерам
В Панель администратора → вкладка Пользователи можно назначить коды камер:
`tam` (тамбур/вход), `pri` (прихожая), `kor` (коридор), `spa` (спальня),
`kab` (кабинет), `det` (детская), `gos` (гостиная), `kuh` (кухня), `bal` (балкон)
