# Демонстрация интерфейса

Четыре одностраничных файла показывают, как выглядит ПЛИИ, без установки:

| Файл | Интерфейс | Язык |
|------|-----------|------|
| `docs/demo/chat-ru.html` | чат, задачи, документы, глубокий анализ | русский |
| `docs/demo/chat-en.html` | чат, задачи, документы, глубокий анализ | английский |
| `docs/demo/admin-ru.html` | админ-панель, все девять вкладок | русский |
| `docs/demo/admin-en.html` | админ-панель, все девять вкладок | английский |

## Как открыть

Скачайте файл и откройте его в браузере. Ни сервер, ни сеть не нужны: все стили,
скрипты, изображения и видео встроены в файл.

Страница начинается с экрана входа. Поля логина и пароля заполнены и заблокированы
(`user` / `user` для чата, `admin` / `admin` для админ-панели); кнопка «Войти» открывает
интерфейс.

## Что настоящее, а что вымышлено

Настоящее: сам интерфейс — шаблоны, CSS и JavaScript текущего релиза, — данные о железе и
моделях машины, на которой собиралась демонстрация, и ответы, разбор документов, картинки и
видео, которые действительно получил продукт.

Вымышлено: учётные записи на экране входа, пользователи в админ-панели, документы, запросы,
резервные копии, камеры и ряды мониторинга. Ни один настоящий аккаунт, чат, документ или
показатель использования в демонстрацию не попадает.

## Почему её нельзя принять за работающий экземпляр

Ни одно действие не отправляет запрос. Любая кнопка — отправить, сгенерировать, удалить,
сохранить, скачать, выйти — отвечает уведомлением, что это демонстрация интерфейса. Работает
только просмотр: переключение между чатом, задачами, документами и сессиями, вкладки
админ-панели, переключатель темы и переключатель «десктоп/телефон».

Полоса над интерфейсом не является частью продукта: на ней метка «демо», переключатель
раскладки и ссылка на другую языковую версию.

## Как пересобрать демонстрацию

Страницы генерируются при подготовке релиза — после повышения версии и после последней
правки интерфейса:

```bash
# 1. Сначала сделайте резервную копию базы: захват ненадолго пишет в неё.
docker exec flai-postgres pg_dump -U flai -d flai > backups/pre-work_$(date +%F_%H-%M-%S).sql

# 2. Снимите демонстрационные данные с работающего экземпляра.
python -m demo.capture --lang all --base-url http://localhost:5000 --password '<пароль демо-аккаунтов>' --force

# 3. Соберите четыре страницы.
python -m demo.build

# 4. Страж падает, если закоммиченная страница разошлась с шаблонами.
pytest tests/test_demo_pages.py -q
```

Захват работает с запущенным экземпляром по HTTP и использует по два одноразовых аккаунта на
язык (`demo_<lang>_chat` и `demo_<lang>_admin`, создаются заранее): он записывает ответы,
скачивает сгенерированные медиафайлы и затем удаляет аккаунты. Если выполнение прервалось,
уборку завершает `python -m demo.capture --cleanup <манифест> --database-url <url>`: фоновые
задачи этих логинов приходится удалять отдельно, потому что штатное удаление аккаунта их
оставляет.

Документы лежат в репозитории готовыми PDF. Они пересобираются только при изменении
вымышленного содержания:

```bash
python -m demo.make_documents
```

## Ограничения и особенности

- Каждая страница — один файл размером до 16 МБ; настоящее десятисекундное видео встроено как есть.
- Демонстрация проверена в Chromium и Firefox при открытии с диска; Safari отдельно не
  поддерживается.
- Мобильная раскладка — это собственная адаптивная вёрстка продукта в iframe шириной 390 px,
  а не уменьшенный скриншот.
