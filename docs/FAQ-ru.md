# Часто задаваемые вопросы

Краткие ответы на самые частые вопросы. Для подробностей переходите по ссылкам.

## Общее

### Что такое FLAI?

Самостоятельно размещаемый, полностью локальный мультимодальный ИИ-ассистент. Он выполняет чат, рассуждения, веб-поиск, поиск по документам, генерацию и редактирование изображений, генерацию видео, распознавание и синтез речи, долговременную память и работу с камерами — на вашем собственном железе, без облачных сервисов на пути. См. [../README-ru.md](../README-ru.md).

### Что-то покидает мою машину?

Нет. Весь инференс выполняется на вашем GPU или CPU, и все данные остаются в вашей базе PostgreSQL и в каталоге загрузок. Единственный исходящий трафик идёт к сервисам, которые настраиваете *вы*: поисковому движку и веб-страницам, загружаемым, когда вы просите FLAI искать или краулить. Каждый пользовательский URL проходит SSRF-гард, отбрасывающий приватные и link-local адреса.

### Какая лицензия?

MIT. См. [../LICENSE](../LICENSE).

### Есть ли размещённая версия?

Нет. FLAI размещается только самостоятельно — в этом и смысл проекта.

## Оборудование

### Нужна ли мне видеокарта NVIDIA?

Нет, но настоятельно рекомендуется. У FLAI два режима развёртывания с одинаковым набором функций:

- **Режим GPU (NVIDIA, CUDA 12.2+)** — полная скорость. Рекомендуется.
- **Только CPU** — всё работает, для генерации медиа в 4–6× медленнее. Генерация изображений и видео автоматически снижает разрешение, чтобы уложиться во временной бюджет.

На GPU NVIDIA минимум — 8 ГБ. См. [Системные требования](../README-ru.md#-системные-требования) и [BENCHMARKS-ru.md](BENCHMARKS-ru.md).

### Что можно делать с 8 ГБ VRAM?

Чат, вызов инструментов, рассуждения, веб-поиск, поиск по документам и генерация изображений — всё помещается. Генерация видео на 8 ГБ впритык, а у больших моделей рассуждений окно контекста будет автоматически уменьшено. Таблица уровней оборудования в README перечисляет, что помещается при каждом размере.

### Можно ли запустить на AMD или Intel?

Пока нет. Поддержка GPU нескольких платформ в работе — см. [ROADMAP-ru.md](ROADMAP-ru.md). Режим только CPU работает везде, где не работает GPU.

### Почему после перезапуска изменилось окно контекста?

Окна контекста автоматически подбираются при развёртывании по метаданным GGUF на диске плюс измеренной ОЗУ/VRAM. Их намеренно не настраивают вручную, поэтому замена модели или расширение VRAM их меняет. См. [CONTEXT-ru.md](CONTEXT-ru.md) и [VRAM_MANAGEMENT-ru.md](VRAM_MANAGEMENT-ru.md).

## Установка

### Нужен ли API-ключ, чтобы пользоваться FLAI?

Нет. FLAI полностью работоспособна без единого внешнего аккаунта. Ключ Tavily — опциональное улучшение качества веб-поиска; без него поиск работает на локальном движке SearXNG. См. [SEARCH-ru.md](SEARCH-ru.md).

### Куда кладутся файлы моделей?

В каталог `models/` (подключается из `./models` в `docker-compose.gpu.yml`). Стартовая конфигурация поставляется без файлов моделей. Команды загрузки, размеры и лицензии — в [MODELS-ru.md](MODELS-ru.md); `deploy.sh` может скачать их за вас.

### Можно ли добавлять модели без перезапуска?

Да. В админ-панели есть **Model Hub**, который ищет GGUF-модели на Hugging Face, показывает оценку по VRAM/ОЗУ до скачивания, скачивает с прогрессом и докачкой и удаляет то, что больше не нужно. См. [MODELS-ru.md](MODELS-ru.md).

### Какие профили compose мне нужны?

`--profile with-image-gen` для изображений, `--profile with-video` для видео, `--profile with-rag` для поиска по документам, `--profile with-voice-piper` или `--profile with-voice-kokoro` для голоса, `--profile with-slm` для долговременной памяти, `--profile with-search` для веб-поиска, `--profile with-crawler` для краулинга сайтов. Каждый опционален; базовый стек — чат. См. [CONFIGURATION-ru.md](CONFIGURATION-ru.md).

### Как стать администратором?

Первая учётная запись, созданная `init_db()`, становится администратором (`admin`, с `service_class=0`). Задайте ей пароль:

```bash
docker exec flai-web flask admin-password <password>
```

## Использование

### Как FLAI решает, что делать с моим сообщением?

LLM-роутер классифицирует каждое сообщение в одну из одиннадцати категорий — поиск по документам, веб-поиск, поиск по истории, офлайн-рассуждения, рассуждения со свежими веб-данными, глубокое изучение сайта, снимок с камеры, запомнить факт, генерация изображения, генерация видео или обычный чат с инструментами. Правил по ключевым словам нет. Полная таблица — в README.

### Почему он не искал в интернете, когда я спросил про актуальную тему?

Часть вопросов намеренно остаётся офлайн — код, тексты, выводы. Анализ текущих событий роутер направляет в веб-поиск. Если ваше сообщение было классифицировано как обычный чат, переформулируйте: указание, что вам нужна *последняя* информация, или просьба что-то найти обычно меняет решение.

### Я вставил ссылку и спросил, что за проект. Почему без поиска?

Одна ссылка с вопросом об этой странице — по замыслу обычный чат: инструмент `read_page` открывает страницу напрямую вместо полного поиска или краулинга. Глубокое изучение сайта (`[-CRAWL-]`) предназначено для явных запросов по всему сайту. См. [SEARCH-ru.md](SEARCH-ru.md).

### Что такое Глубокий анализ?

Режим рассуждений для серьёзной работы с несколькими документами: сравнение договоров, извлечение всех исключений из политики, построение отчёта по набору текстов. Модель прорабатывает материал в цикле, а не отвечает по результату одного извлечения. См. [DEEP_ANALYSIS-ru.md](DEEP_ANALYSIS-ru.md).

### Можно ли остановить выполняющуюся задачу?

Да — нажмите **Отмена**. Отмена поддерживается для генерации и редактирования изображений, генерации видео (которая также перезапускает видеоконтейнер) и стриминговых задач чата.

### Почему чат подвисает, пока генерируется видео?

Так задумано. GPU-задачи выполняются строго по одной, а VRAM между ними безусловно очищается, поэтому чат ждёт окончания видео-задачи. См. [ARCHITECTURE-ru.md](ARCHITECTURE-ru.md).

## Данные, приватность и пользователи

### Где находятся мои данные?

В PostgreSQL (сообщения, сессии, пользователи, метаданные документов) и в подключённых каталогах (`./data`, `./uploads`, `./models`). Полные резервные копии доступны из админ-панели. См. [ADMINISTRATION-ru.md](ADMINISTRATION-ru.md).

### Что произойдёт с моими данными, если удалить учётную запись?

Удалятся все. Удаление пользователя стирает его сообщения, сессии, загруженные документы, профиль памяти SLM и API-ключи. Это путь удаления по GDPR, а не мягкое удаление. См. [ADMINISTRATION-ru.md](ADMINISTRATION-ru.md).

### Могут ли несколько человек пользоваться одним инстансом?

Да, с одной оговоркой: FLAI держит одну очередь GPU, поэтому тяжёлая генерация медиа одним пользователем задерживает всех. Для обычного чата и поиска несколько пользователей спокойно делят один инстанс. Роутер использует историю сессии и долговременные факты, чтобы различать «ты», но сессии у каждого пользователя свои.

### Могу ли я использовать FLAI из своего приложения?

Да — публичный OpenAI-совместимый API. `/v1/chat/completions`, `/v1/embeddings`, генерация изображений и видео, распознавание и синтез речи, загрузка файлов, сессии и управление задачами. Ключи выдаются на пользователя. Интерактивная документация — на `/v1/docs`. См. [API-ru.md](API-ru.md).

### Ограничен ли API по частоте запросов?

Да: 60 запросов в минуту и 1000 в час, счёт по владельцу API-ключа (все ключи одного пользователя делят один бюджет). См. [API-ru.md](API-ru.md).

## Эксплуатация

### Как сделать резервную копию?

Админ-панель → Backups или CLI. Полная копия включает базу данных, загрузки и брендинг. См. [ADMINISTRATION-ru.md](ADMINISTRATION-ru.md).

### Как следить за системой?

`/health` возвращает JSON-статус; `/metrics` отдаёт метрики Prometheus, включая `flai_web_info`. В админ-панели есть вкладка мониторинга и обзор оборудования. См. [MONITORING-ru.md](MONITORING-ru.md).

### Что-то сломалось

Начните с [TROUBLESHOOTING-ru.md](TROUBLESHOOTING-ru.md). Если вашей проблемы там нет, проверьте [../CHANGELOG.md](../CHANGELOG.md) — возможно, это известная регрессия.
