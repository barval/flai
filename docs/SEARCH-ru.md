# Веб-поиск, чтение страниц и краулинг

## 🌐 Веб-поиск Tavily (личный ключ пользователя)

Веб-поиск всегда шёл через самостоятельно размещённый метапоисковик **SearXNG** — он бесплатный, но ограниченный: сниппеты короткие, в выдаче перевешивают популярные сайты, а лимиты поисковых движков легко исчерпываются. Начиная с v12.4 каждый пользователь может подключить собственный **API-ключ Tavily** — это специализированный поисковый API для ИИ, у которого на бесплатном тарифе **1000 кредитов в месяц** (базовый поиск стоит 1 кредит), он возвращает чистые, содержательные сниппеты и заметно лучше отвечает на нишевые запросы (репозитории, документация, запросы цен), чем обычный метапоисковик.

**Как включить:**

1. Создайте бесплатный аккаунт на [app.tavily.com](https://app.tavily.com/home) и скопируйте API-ключ (`tvly-…`).
2. В FLAI нажмите на **своё имя в шапке** — откроется всплывающее окно профиля.
3. В блоке «Поиск в Интернет через Tavily» вставьте ключ и нажмите **Добавить ключ**. Перед сохранением ключ проверяется запросом к эндпоинту `/usage` Tavily — неверный ключ отклоняется и никогда не сохраняется.
4. Затем в окне отображается маска ключа (`tvly-…xxxx`), лимит тарифа, израсходованные за месяц кредиты и остаток кредитов. Ключ можно в любой момент удалить кнопкой **Удалить ключ**; на пользователя разрешён только один ключ, поэтому для добавления второго нужно удалить первый.

**Как это работает дальше:**

- Каждый веб-поиск (категория роутера `[-SEARCH-]`, инструмент `web_search` в чате, выборки глубокого анализа и чат через `/v1`) теперь обращается **сначала к Tavily**, а к локальному SearXNG автоматически возвращается, если ключ отсутствует, провайдер отключён, ключ отклонён, месячная квота исчерпана или сервис недоступен — поиск никогда не ломается, просто используется более медленный бесплатный путь.
- Тонкий ответ Tavily бесплатно дополняется результатами SearXNG, вместо того чтобы тратить второй кредит на тот же запрос.
- Ключ хранится только на сервере, никогда не возвращается в браузер (только маска `tvly-…xxxx`) и никогда не попадает в логи.
- Администраторы видят остаток кредитов Tavily и количество ключей FLAI у каждого пользователя во вкладке «Пользователи» админ-панели (данные загружаются отложенно и кэшируются на 5 минут, поэтому открытие страницы не тратит кредиты).
- Инстанс полностью работоспособен и без единого ключа Tavily — это необязательное улучшение качества, а не требование.

## 🕸️ Чтение сайтов и глубокое изучение (Crawl4AI)

Для вставленных в чат ссылок и для запросов на глубокое изучение целых сайтов FLAI может использовать sidecar **Crawl4AI** (включается флагом `--with-crawler` при развёртывании либо установкой `CRAWL_ENABLED=true` в `.env`).

**`read_page(url)` — одна ссылка в настоящем браузере**

Когда вы вставляете ссылку (например, страницу документации, листинг товаров, issue на GitHub), категория `[-CRAWL-]` **не** срабатывает — вместо неё автоматически срабатывает нативный инструмент `read_page` (быстрый воркер, без слота в очереди, без GPU). Он открывает страницу в настоящем браузере (Playwright + Chromium внутри sidecar), извлекает чистый markdown через trafilatura и возвращает её модели. Инструмент регистрируется только когда контейнер краулера доступен; если контейнер не запущен, запрос идёт по обычному пути, и ссылка не читается.

**`[-CRAWL-]` — глубокое изучение сайта**

Когда пользователь прямо просит «изучить этот сайт», «проанализировать всю документацию», «прочитать всё на example.com», роутер выдаёт маркер `[-CRAWL-]`. После этого FLAI:

1. Краулит стартовый домен (до `CRAWL_MAX_PAGES=50`, `CRAWL_MAX_DEPTH=3`, `CRAWL_TIMEOUT_S=300`), переходя только по ссылкам того же домена.
2. Объединяет страницы в секции `## <url>` с ограничением `CRAWL_MAX_TOTAL_CHARS=1,000,000` (лимит на одну страницу — `CRAWL_MAX_PAGE_CHARS=50,000`).
3. **Заменяет** любой существующий пользовательский документ, имя файла которого совпадает с регистрируемым доменом (например, `docs.example.com` → `docs.example.com.txt`). При замене старая запись RAG, файл и строка БД удаляются до записи новых.
4. Синхронно запускает **общее ядро индексации документов** (тот же конвейер, что и при загрузке документов) — эмбеддинги → Qdrant → RAG.
5. **Переочередивает рассуждение** с `rag_source="crawler"`; флаг `file_coverage` гарантирует, что свежий документ попадёт в промпт.
6. Полученный документ появляется в вашей **панели «Документы»** под именем домена и готов к обычному RAG, дополнению результатов веб-поиска и **глубокому анализу (RLM)**.

**Деградация**

| Ситуация | Поведение |
|---|---|
| Контейнер отключён или не запущен | `read_page` не регистрируется; `[-CRAWL-]` завершается локализованным сообщением (никогда не переходит молча на облегчённый поиск) |
| Сайт отказывает в автоматическом доступе (антибот) | Показывается уведомление, и FLAI **возвращается к обычному веб-поиску** (Tavily → SearXNG), чтобы вы всё равно получили ответ |
| 0 пригодных страниц | Локализованная мягкая ошибка с предложением использовать обычный поиск |
| Достигнуты лимиты | Аккуратная остановка; собранный префикс индексируется |
| Квота документов исчерпана | Локализованная ошибка о квоте; содержимое отбрасывается |

**Защита от SSRF**

Каждый URL проходит `app/crawler_guard.py:validate_url()` до выхода из приложения: допускаются только http/https, все резолвящиеся адреса должны быть глобально маршрутизируемыми (запрещены RFC 1918, loopback, link-local, 169.254.169.254, CGNAT, ULA, multicast), а учётные данные в URL отвергаются. Стартовый URL глубже корня домена (например, `https://site.com/docs/`) ограничивает обход этим префиксом пути — соседние разделы портала не обходятся. Trafilatura остаётся первым экстрактором везде, где она работает; краулер — вторым шагом для страниц, требующих настоящего браузера. Некоторые крупные магазины (например, DNS-Shop) полностью блокируют IP дата-центров — для таких сайтов FLAI автоматически отвечает через обычный поиск.

**Стадии прогресса**

Пока идёт обход, в чате вы увидите транслируемые статусные подписи:
- `crawl_start` — «Начинаю обход веб-страниц...»
- `crawl_page` (с номером страницы) — «Обхожу страницу N...»
- `crawl_indexing` — «Индексирую полученный контент...»
