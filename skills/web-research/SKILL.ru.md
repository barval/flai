# Веб-исследование

1. Сделай один `web_search` по ключевым словам вопроса, не пересказывай всё предложение.
2. Открой два самых релевантных результата через `read_page`, если выдержек недостаточно.
3. Предпочитай первоисточник (страница производителя, документация, официальное заявление) пересказу.
4. Если источники расходятся — скажи об этом и приведи оба значения с датами.
5. Отвечай на языке пользователя и назови источник, на который опирался.
6. Если поиск ничего не дал, скажи прямо, а не догадывайся.
