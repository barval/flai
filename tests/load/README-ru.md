# Нагрузочное тестирование с Locust

Для запуска нагрузочных тестов:

1. Установите Locust: `pip install locust`
2. Убедитесь, что ваше приложение запущено (например, `docker-compose up`)
3. Запустите Locust: `locust -f tests/load/locustfile.py --host http://localhost:5000`
4. Откройте браузер по адресу http://localhost:8089 и запустите тест.

Вы можете настроить количество пользователей и скорость их появления.
